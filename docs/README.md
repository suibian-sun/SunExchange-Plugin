# SunExchange 插件开发文档

本目录按「SDK 参考 + 指南」组织，覆盖从零到发布一个插件的完整路径。

| 文档 | 类型 | 内容 |
| --- | --- | --- |
| [SDK 开发指南](sdk-guide.md) | 指南 | 插件开发全流程：生命周期、事件、命令、插件间 API、构建与加载（推荐先读） |
| [SDK API 参考](sdk-reference.md) | 参考 | `sdk` 包全部类型、常量、方法速查 |
| [脚手架 CLI 指南](cli-guide.md) | 指南 | 用 `sunexchange-plugin new` 一键生成插件骨架 |

## 快速入口

- 想快速上手：读 [SDK 开发指南](sdk-guide.md)，用 [CLI](cli-guide.md) 生成插件。
- 查 API：翻 [SDK API 参考](sdk-reference.md)。
- 看真实代码：`examples/server/entry`（全能力示例）与 `examples/netease/basic`（网易端示例）。
